# Historical Financial Analysis

This workbook contains bioMérieux's audited historical financial information for FY2023–FY2025.

## Contents

- Consolidated income statement
- Consolidated balance sheet
- Consolidated cash-flow statement
- Revenue breakdown
- Financial ratios
- Source references and reconciliation checks

Historical source data is shown in blue, formulas in black, and cross-sheet links in green.
